# Security By Design & Universal State Engine

## 1. Security By Design: Zero Trust OS

В основе KAZAH OS лежит принцип **Zero Trust (Нулевого доверия)**.
Традиционные ОС (Windows, Linux) доверяют процессам на основе учетной записи (пользователь или Root/Administrator). Если приложение запущено от имени Администратора, оно может сделать с системой всё что угодно.

KAZAH OS ломает эту парадигму.

### Process Isolation & Sandboxing
Каждое приложение (даже системное) запускается в изолированной песочнице (Sandbox) по умолчанию (концепция Universal Sandbox).
У приложения нет доступа к:
- Файловой системе за пределами своей директории (пока пользователь явно не выдаст доступ к файлу через File Picker).
- Сети (пока не будет запрошено разрешение).
- Камере, микрофону, геолокации.
- Памяти других процессов (аппаратно запрещено MMU).

### Capability Model
Вместо прав POSIX или ACL в Windows, используется модель Capabilities (Мандатов). Процесс при старте получает набор криптографических токенов (capabilities), разрешающих ему конкретные системные вызовы. Без токена ядро отклонит запрос, даже если процесс системный.

### Signed Drivers & Modules
Все драйверы (уровня Ring 3 System Service Mesh) и модули должны быть подписаны сертификатом доверенного разработчика. KAZAH Kernel отказывается загружать неподписанный код.

## 2. Universal State Engine (USE)

Самая инновационная фича KAZAH OS — транзакционная система состояний.
**Universal State Engine (USE)** логирует каждое значимое изменение в операционной системе.

### Концепция "ОС как База Данных"
Все настройки ОС, реестр компонентов, установленные приложения и драйверы хранятся не просто в виде файлов, а в виде графа состояний.
Действия пользователя (установка программы, обновление драйвера) оформляются как **транзакция**.

Если транзакция не завершилась успешно (например, отключили свет при установке драйвера), она откатывается. Никаких "сломанных обновлений".

### Time Machine для всей системы
Благодаря интеграции USE с файловой системой KFS (Kazah File System, поддерживающей Copy-on-Write и Snapshots):
Пользователь может буквально откатить состояние **всей операционной системы** на конкретное время (например, на "Вчера, 14:31:25").

**Что откатывается:**
- Версии драйверов.
- Установленные/удаленные приложения.
- Системные конфигурации.
- Файлы (опционально, можно выбрать сохранение пользовательских файлов).

Эта функция делает KAZAH OS практически неуязвимой для Ransomware (вирусов-вымогателей). Даже если вирус зашифрует файлы (что маловероятно из-за Sandboxing), USE и KFS мгновенно откатят эти изменения, так как шифрование - это просто создание новой версии файла, а старая (здоровая) версия остается в Snapshot-е.
